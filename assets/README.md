# 교재 원화 넣는 곳

파일을 넣으면 스토리 카드에 자동으로 쓰이고, 없으면 색 원으로 된 자리표시 그림이 나와요.

- `stickers/<단어>.png` — 단원 어휘 스티커 (예: `stickers/robot.png`, 띄어쓰기는 `_`: `stickers/teddy_bear.png`)
- `characters/<이름>.png` — `wacky.png`, `jack.png`, `amy.png`, `tom.png`, `mom.png`
- `backgrounds/<scene>.png` — `classroom`, `toyroom`, `picnic`, `park`, `home`, `zoo`, `petshop`, `room`

배경이 투명한 PNG를 권장해요. 교재 원화는 회사 자산이라 사용 범위를 담당자와 확인한 뒤 넣어주세요.
